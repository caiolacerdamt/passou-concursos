# Abrir um concurso

Este arquivo é um **adaptador**. O roteiro canônico — e único — mora em:

**`.agents/skills/abrir-concurso/SKILL.md`**

Leia-o agora, na íntegra, e siga o que está lá. Nenhuma regra de validação, de
segurança ou de escrita existe só aqui: se algum dia este arquivo e a fonte
canônica discordarem, **a fonte canônica vence**, e a divergência é bug.

O Codex lê a fonte canônica diretamente. Este adaptador existe para que o Claude
Code chegue ao mesmo lugar, pelo mesmo caminho, com o mesmo texto.
